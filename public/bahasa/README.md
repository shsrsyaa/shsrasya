# shsrsyaa-sites (Portofolio HTML, CSS, JavaScript)

Website portofolio pribadi **I P. G. Divy Sahasrasya (Rasya)** yang dibangun dengan murni **HTML5, CSS3, dan Vanilla JavaScript** (tanpa dependency, tanpa framework, tanpa bundler).

## 📁 Struktur Berkas

```
.
├── index.html        # Berkas HTML utama (Bahasa Indonesia)
├── style.css         # Berkas tata letak dan tema visual modern
├── script.js         # Logika interaktif (parallaks, partikel kanvas, modal CV, audio tap)
└── assets/           # Foto kampus ITS dan foto profil
```

## 🚀 Cara Mengunggah ke GitHub (shsrsyaa/shsrsyaa)

Untuk memasukkan berkas-berkas ini ke repositori `https://github.com/shsrsyaa/shsrsyaa.git`:

1. Salin seluruh isi folder ini (`index.html`, `style.css`, `script.js`, dan folder `assets`) ke dalam repositori lokal Anda.
2. Buka terminal di folder repositori, lalu jalankan perintah:
   ```bash
   git add .
   git commit -m "Update portfolio ke HTML, CSS, JS Bahasa Indonesia"
   git push origin main
   ```
3. **Mengaktifkan GitHub Pages (Gratis):**
   - Buka repositori Anda di GitHub: `https://github.com/shsrsyaa/shsrsyaa`
   - Klik tab **Settings** > menu **Pages** (di sebelah kiri).
   - Pada bagian **Build and deployment** > **Branch**, pilih cabang `main` dan folder `/ (root)`.
   - Klik **Save**.
   - Website Anda akan langsung tayang secara otomatis di: `https://shsrsyaa.github.io/shsrsyaa/` atau `https://shsrsyaa.github.io/`!
